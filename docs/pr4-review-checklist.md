# PR 4 review checklist

- [ ] Story images always have a stable local fallback from the approved four-image pool.
- [ ] Remote researched images never leave a visible broken-image state.
- [ ] Overview surfaces the immediate high-impact release before it prints.
- [ ] The release card updates in place when an actual becomes available.
- [ ] High-impact releases are linked to active Stories and research questions.
- [ ] Four canonical research slots are visible as health states.
- [ ] Articles expose Article Charts and Change Meter views.
- [ ] Article idea states use current price and article-native levels where available.
- [ ] No mock production data is inserted.
- [ ] No Supabase migration is applied.
- [ ] Production and main remain unchanged.
