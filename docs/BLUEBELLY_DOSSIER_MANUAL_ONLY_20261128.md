# Dossier manual-only policy — 28 November 2026

Owner direction: Dossiers are private reference material for manual viewing and explicitly requested analysis. Scheduled source collection, Notion research delivery, Creator Intelligence and market monitoring do not require a new Dossier. Historical Dossiers, manual read and explicitly selected manual run modes are retained. The four existing post-intake slots retain only the derived embedding refresh in source-only operation; no automatic Dossier model, persistence or D7 sync. The legacy separately opt-in private PDF path is unchanged. GitHub research fallback no longer chains to Dossier generation. Old checkpoints are historical receipts, not mandatory freshness targets. No new cron, data migration, permission changes or deletion. A stale historical Dossier is not an acquisition failure. Research Gap dependency and presentation status audit remains separate.
