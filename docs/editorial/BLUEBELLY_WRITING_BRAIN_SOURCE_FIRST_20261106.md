## Evidence contract for a future Writing Brain run

1. Freeze `RUN_ASOF_UTC` and MYT/ET labels; identify actual last completed NYSE session ET without equating it to a newer Asian release timestamp. Read the exact most recent relevant full MacroPulse Post and bounded Research Investigation Run/Registry. Use already-qualified Bluebelly source receipts (the installed **Bluebelly Read-Only Desk** plugin/Supabase connector) rather than regenerating an owner Daily Intelligence HTML summary.
2. Prefer **current, original source** `https://` URLs, original source record IDs, source/event published UTC clock, observed/fetched UTC clock, verification status, issuing authority, metric/period, matched frozen expectation if it exists, and next scheduled date. A source lookup failure or delayed press intake is **UNAVAILABLE / COVERAGE GAP**, never `NO NEWS`.
3. For price or rates confirmation, use a dated market observation with the same measured basis and explicitly state frequency and units. An independent daily close is not an observed 5-minute causal reaction; missing quote/consensus = **UNKNOWN**. Creator commentary and research hypotheses are attributed leads, not original records.
4. **P0 first:** independently UPSERT exactly **three** distinct source-linked ideas to the *existing* `public.blue_desk_editorial_slates`, then SELECT/read back by `day_myt`. Preserve stable unique `ideaId`, rank, COTD/OB/BOTH, hook, source links, catalyst, expectation or UNKNOWN, price reaction or UNKNOWN, mechanism, strongest countercase, next trigger, technical check and `missingProof`. A partial slate is acceptable if at least one valid original URL per idea and limitations are explicit. No auto-publication.
5. `parentReportId`, `parentReportSha256`, `reportSessionET` are **optional compatibility fields**. Set them only if a specific existing owner HTML edition was independently read and its ID, SHA and actual US cash session were validated. Otherwise **omit all three**, note `SOURCE_FIRST_NO_REPORT_PARENT` and persist the original source IDs/URLs/clocks in existing `material_event_receipts` when the schema accepts them, or notes and `sources` with truthful status. Never fabricate parent identity or generate a report solely for a parent ID.
6. P1 optionally reuse an existing Work HTML report for editorial context; do not initiate a new full Daily Intelligence HTML or PDF purely for My Desk or for the slate-parent requirement. Detailed writing takes place inside ChatGPT or the user's established writing workflow. Existing *Research Investigation* Work output is unchanged by this UI/fallback release.
7. Final receipt: MYT/ET, source-qualified IDs and watermarks, three idea IDs and SELECT check, true state `CURRENT_PERSISTED` / `CURRENT_PARTIAL` / `MISSING` or `BLOCKED`, still unknown facts and next owner. `source_checked` means the producer asserted its checks, not an independent on-site re-verification of all source claims.
