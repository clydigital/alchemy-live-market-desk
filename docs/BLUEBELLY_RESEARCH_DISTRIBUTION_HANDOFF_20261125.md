# Bluebelly research distribution — operating bridge (25 Nov 2026)

Extends the existing Notion Sitemap / Architecture operating standard; no new scheduler, database, public publication rule, or automatic thesis writer.

## Agent handoff
1. Retain raw or partial inputs using existing intake. Preserve source identity, publication time versus capture time, attribution and partial status.
2. Read the existing authenticated `GET /api/owner/daily-research` packet. The new `researchDistribution` field exposes bounded accepted video revisions, actual digest source membership, explicit destinations and research tests. An unavailable field never blocks the rest of the packet. No automatic provider refresh is implied.
3. For each material destination, ChatGPT synthesises the argument, independent evidence, countercase and next test. Use Markets Compare / Divergence Watch and relevant original-source evidence. Coalesce overlapping claims; ignore low-materiality routes. Do not convert creator opinions to facts.
4. For Creator Intel, update the existing Notion single JSON digest (creator-signals-v1) or authorised immutable Work digest. Preserve latest eligible heads and existing useful material; supplied inputs may carry null identity/date, description-only input is not a transcript. Exact source membership alone is not proof of content. Inspect the relevant signals and coverage in the selected digest.
5. For lens reasoning, use the existing reviewed question revision/Story or authorised evidence route; verify adequate evidence for each material claim. For Investor Mindset, use the existing authorised Dossier V2 writer with actual inputs. For Crash, inspect the existing aggregate and independent Compass; do not hardcode an opinion score. For Newsroom, use the original-source verification and existing editorial review route. No new automatic publications.
6. Report independent results per material destination: saved, reviewed, admitted, displayed, pending, unavailable or not needed; include the relevant record/version and as-of when available. A failed branch never invalidates successful capture. Do not force every destination to be revised, or use a generic last-updated timestamp as proof of propagation.

The routing helper is intentionally owner-only, bounded to accepted/published video items revised within 48 hours. It supplies candidate handoffs and exact digest-source checks, not canonical evidence or actual publication receipts. Unmatched source IDs remain visible for analyst reconciliation; a missing video ID does not justify inventing one. Other sources continue to use the existing MacroPulse/Investigation paths.
