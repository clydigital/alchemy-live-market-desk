# MD8 phase D — Point-in-time historical validation (manual, private)

Use the existing offline sentiment backtests for exploratory episode/strategy studies, not proof that the current BAR, institutional VaR, or creator-sentiment panel predicts direction. This new evaluator is a read-only diagnostic of frozen, predeclared signals on the same completed session grid.

Run with the existing Node 22+ convention:
```sh
node --experimental-strip-types scripts/evaluate-point-in-time-signals.ts /private/path/frozen-input.json > /private/path/validation-report.json
```
Keep raw exports and private outcomes outside Git and public editorial output. Use an independently verified exchange calendar, including missing session placeholders, stable price basis and comparable benchmark. Supply instrument, benchmarkInstrument, signalDefinition, modifierDefinition, trendDefinition, regimeDefinition, priceBasis, sourceManifest, calendarAttestation, frozenAt (offset-aware), trainEnd (session date), minSample (>=20), and ordered sessions. Each session has date, closeAt, price, benchmark, and signal/modifier/trend/regime/var95/var99: null or {value,observedAt,availableAt,sourceId}. Availability is the first point the information was knowable, not retrieval time or an assumed backdated release. Null or late data remain unavailable. VaR uses percent loss units, not decimals; match the model's asset exposure. For volatility anchors, retain original dated observations and release clocks. Do not reconstruct past BAR from today's definition unless explicitly labelled retrospective and independently validate the definition and original input clocks.

The fixed grid evaluates 1/5/20/60 session outcomes from the next close; training windows that cross the holdout boundary are purged. Compare signal vs no signal, signal+modifier vs signal without modifier, signal within trend vs trend-only and unconditional coverage within each ex-ante regime. Report return, arithmetic excess vs benchmark, positive frequency, drawdown and annualised realised RMS log volatility. The shared coverage cohort requires all four timed directional fields; it is a deliberate comparability filter, not complete population coverage. Holdout outcomes are separate from training. No signal-dependent sampling grid or post-hoc threshold optimisation. VaR calibration uses the separate holdout cohort and next-session log loss, with 95/99% exception rates versus 5/1%, clustering reset at missing sessions. Neither risk exception rates nor risk percentiles imply market direction.

This is an initial descriptive evaluator, not a walk-forward inference engine. Report sizes even when below minimum; never promote a signal based on this output. No block-bootstrap confidence intervals, multi-test control, adjusted strategy costs, return probabilities or model approval are implemented. Next validation gates: verify immutable historical availability and calendar completeness; check sample sizes and missingness; freeze thresholds before holdout; perform walk-forward evaluation and regime robustness with uncertainty intervals and multiple-testing control; independently adjudicate forecast and causal outcomes. BAR formula and point-in-time creator sentiment history remain unverified. No production dataset was evaluated by this change.

No new provider, cron, database schema, network acquisition, forecast writeback, automatic decision or public page. Existing research automations and historical shadow evaluator are unchanged.
